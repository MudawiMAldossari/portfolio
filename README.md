# Mudawi Aldossari: portfolio website

My personal portfolio site, in English and Arabic: research, projects, practical training, skills and my CV.

**Live site:** https://mudawi-aldossari.onrender.com

It is a static site (`index.html`, images in `img/`, and `cv.pdf`) hosted on Render as a Static Site with no build step. Every change pushed to `main` is published automatically.
